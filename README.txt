# 🏢 Datahall Review Program (데이터홀 검토 프로그램)

**데이터센터 설계 시 IT 랙 배치, 냉각 설비(FWU, CDU), 그리고 건축 구조(기둥, 보, 슬라브) 간의 물리적 간섭을 사전에 검토하고 조율하기 위한 웹 기반 대시보드입니다.**

## 💡 프로젝트 개요

건축/설비 엔지니어 및 프로젝트 관리자가 복잡한 CAD 소프트웨어 없이도 웹 브라우저 상에서 주요 제원(부하, 랙 크기, 기둥 간격 등)을 입력하여 **실시간으로 도면(평면도, 단면도)을 생성**하고, 공간 적합성 및 기류(SA/RA) 상태를 즉각적으로 확인할 수 있도록 돕습니다.

## ✨ 주요 기능 (Key Features)

* **📐 실시간 2D 도면 렌더링**
* 입력된 수치에 따라 평면도(Plan View) 및 단면도/입면도(Section/Elevation View) 자동 생성
* 데이터홀(IT Racks), 복도(Hot/Cold Aisle), 갤러리(FWU/CDU), 건축 구조(기둥, 보, 슬라브) 및 경계 벽체 시각화


* **⚙️ 하이브리드 냉각 부하 자동 산출 (AC & LC)**
* 전체 IT Load 대비 공랭식(AC, FWU)과 수랭식(LC, CDU)의 담당 비율(%) 설정 가능
* 요구되는 CMH(풍량), CDU 대수, 유효 개구율 및 적층 높이 자동 계산
* CDU 유닛의 갤러리 내 균등 배치(Interleaving) 알고리즘 적용


* **⚠️ 건축 간섭 및 기류 검토**
* 기둥 사이 물리적 간섭 여부 자동 판별 (OK / 간섭 발생)
* 보 하단 RA(환기) 여유 공간 및 예상 RA 풍속 계산
* SA/RA 기류 방향 및 예상 온도/풍속 애니메이션 시각화


* **📏 정밀 치수 측정 툴 (CAD 방식)**
* 마우스 클릭 기반의 길이 측정 기능
* **자동 스냅(OSNAP):** 객체의 꼭지점, 중간점 및 수직 교차점 자석 스냅 지원
* **단축키 지원:** `Space`(측정 툴 토글), `Shift`(수평/수직 직교 모드 고정), `ESC`(선 긋기 취소 및 모드 종료)


* **🌐 다국어 및 데이터 관리**
* 한국어 / 영어(English) UI 실시간 전환
* 브라우저 로컬 스토리지 임시 저장
* `.json` 파일 형식으로 설정값 내보내기 및 불러오기 기능 지원



## 🛠 기술 스택 (Tech Stack)

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (외부 라이브러리/프레임워크 미사용)
* **Graphics:** DOM 기반 CSS Transform & SVG
* **Deployment:** 정적 웹 호스팅 환경(Vercel, GitHub Pages 등)에서 즉시 구동 가능

## 🚀 설치 및 실행 방법 (Installation & Usage)

별도의 빌드 과정이나 서버 설치가 필요 없는 순수 프론트엔드 프로젝트입니다.

1. 본 저장소의 파일들을 다운로드합니다. (`index.html`, `style.css`, `script.js`)
2. 웹 브라우저(Chrome, Edge 등)에서 `index.html` 파일을 더블클릭하여 실행합니다.
3. 좌측 입력 패널에서 **데이터홀, 설비, 건축 제원**을 수정하면 우측 도면에 즉각 반영됩니다.

## ⌨️ 치수 측정 툴 단축키 (Shortcuts)

도면 영역(우측 패널)에 마우스를 올린 상태에서 아래 단축키를 사용할 수 있습니다.

* `Space` : 줄자(측정 툴) 켜기 / 끄기
* `Click` : 시작점 지정 및 끝점 지정 (2-Click 방식)
* `Shift` + `마우스 이동` : 수평 또는 수직으로만 선 긋기 (직교 모드)
* `ESC` : 현재 긋고 있던 선 취소 (한 번 더 누르면 측정 툴 완전히 끄기)

### 1. 터미널(Terminal) 기본 상식

터미널은 마우스(GUI) 대신 **텍스트(CLI, Command Line Interface)로 컴퓨터에 명령을 내리는 창**입니다.
가장 중요한 핵심은 **"내가 지금 어느 폴더(디렉토리)에 있는가?"** 입니다. 모든 명령어는 '현재 머물고 있는 폴더'를 기준으로 실행됩니다.

---

### 2. 필수 터미널 명령어 (파일 및 폴더 관리)

*※ Mac(Linux)과 Windows(명령 프롬프트/PowerShell)에서 공통으로 쓰이거나 약간 다를 수 있습니다.*

* **`pwd`** (Print Working Directory)
* **기능:** 내가 현재 위치한 폴더의 전체 경로를 보여줍니다.


* **`ls`** (Windows cmd에서는 **`dir`**)
* **기능:** 현재 폴더 안에 있는 파일과 폴더 목록을 보여줍니다.
* *Tip:* `ls -al`을 치면 숨김 파일까지 자세히 볼 수 있습니다.


* **`cd 폴더명`** (Change Directory)
* **기능:** 다른 폴더로 이동합니다. (예: `cd desktop` -> 바탕화면으로 이동)
* **`cd ..`** : 상위(뒤로 가기) 폴더로 이동합니다.


* **`mkdir 폴더명`** (Make Directory)
* **기능:** 새로운 폴더를 생성합니다. (예: `mkdir my-project`)


* **`clear`** (Windows cmd에서는 **`cls`**)
* **기능:** 지저분해진 터미널 화면을 깨끗하게 지웁니다.



---

### 3. Git 명령어 (버전 관리 및 백업)

작성한 코드를 저장하고 GitHub 등에 업로드할 때 사용하는 명령어입니다. 주로 3단계(**Add -> Commit -> Push**)로 이루어집니다.

* **`git init`**
* **기능:** 현재 폴더에 Git(버전 관리)을 적용하기 시작합니다. (프로젝트 시작 시 한 번만 실행)


* **`git status`**
* **기능:** 현재 수정되거나 새로 추가된 파일이 있는지 상태를 확인합니다. (가장 자주 쓰는 명령어)


* **`git add .`**
* **기능:** 변경된 **모든** 파일을 저장소에 올릴 준비(Staging)를 합니다. (`.`은 전체를 의미)


* **`git commit -m "메시지"`**
* **기능:** 변경 사항을 내 컴퓨터에 확정(저장)하며, 메모를 남깁니다.
* *(예: `git commit -m "FWU 크기 로직 수정 및 색상 변경"`)*


* **`git push`**
* **기능:** 내 컴퓨터에 Commit된 내역을 GitHub 등 원격 서버(온라인)로 업로드합니다.


* **`git pull`**
* **기능:** 온라인 저장소에 있는 최신 코드를 내 컴퓨터로 다운로드하여 업데이트합니다.



---

### 4. 실행 명령어: `npm start` vs `npx serve`의 차이

프론트엔드 개발 시 화면을 띄우기 위해 가장 많이 헷갈리는 두 명령어입니다.

#### ① `npm start` (개발용 엔진 시동)

* **의미:** `package.json` 파일 안에 정의된 `start` 스크립트를 실행하라는 명령어입니다.
* **특징:**
* React, Vue 같은 프레임워크나 Node.js 백엔드 서버를 켤 때 주로 사용합니다.
* 코드를 수정하고 저장하면 브라우저가 **자동으로 새로고침(Hot-Reload)** 되는 기능이 포함된 복잡한 개발용 서버를 띄웁니다.
* 프로젝트 내에 `package.json` 파일이 꼭 있어야 작동합니다.



#### ② `npx serve` (정적 파일 미니 웹서버)

* **의미:** 내 컴퓨터에 임시로 가벼운 웹 서버를 열어, **현재 폴더에 있는 HTML/CSS/JS 파일을 브라우저에 띄워주는** 명령어입니다.
* **특징:**
* 빌드가 끝난 완성본이나, 현재 만드신 대시보드처럼 **순수 HTML/CSS/JS로만 이루어진 프로젝트(정적 파일)를 확인할 때** 사용합니다.
* `npx`는 컴퓨터에 프로그램을 설치하지 않고, 온라인에서 `serve`라는 툴을 일회성으로 다운받아 즉시 실행해 줍니다.
* 명령어를 치면 `http://localhost:3000` 같은 주소가 나오고, 이를 브라우저에 입력하면 화면이 뜹니다.



**💡 요약하자면:**

* **React 같은 복잡한 개발을 하고 있다면?** 👉 `npm start` (또는 `npm run dev`)
* **지금 만드신 HTML/CSS/JS 도면 대시보드를 내 PC에서 깔끔하게 웹 사이트처럼 띄워보고 싶다면?** 👉 해당 폴더로 이동 후 `npx serve` 입력

### 🌟 터미널 사용 꿀팁 (단축키)

* **`Tab` 키 자동 완성:** 폴더나 파일 이름을 칠 때 첫 몇 글자만 치고 `Tab`을 누르면 이름이 자동으로 완성됩니다. (오타 방지 및 속도 향상)
* **`위/아래 화살표` (↑, ↓):** 이전에 입력했던 명령어들의 기록(History)을 불러옵니다. 똑같은 명령어를 다시 칠 필요가 없습니다.
* **`Ctrl + C`:** 현재 실행 중인 프로그램이나 서버(`npm start`, `npx serve` 등)를 강제로 종료(중단)할 때 사용합니다.
